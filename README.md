# Visore Pezzi 1:1

Visualizzatore di assiemi e pezzi (STEP, STL, 3MF, GLB, ZIP) per PC e Meta Quest 3, in realtà mista a scala 1:1.

- `index.html`: la pagina (un solo file).
- `occt-import-js.wasm`: lettore STEP, va tenuto accanto alla pagina.

I modelli si aprono in locale dal dispositivo: non vengono caricati su questo sito.
